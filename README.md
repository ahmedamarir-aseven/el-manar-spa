# El Manar SPA & Wellness

A modern, responsive web application for El Manar Spa — a luxury wellness sanctuary offering traditional Moroccan hammam rituals, massages, body care treatments, and relaxation experiences.

## Overview

El Manar SPA provides a serene digital booking and discovery experience for clients seeking traditional and contemporary wellness rituals. The interface features a full service catalog, photo gallery, client reviews, location details, and direct contact booking.

## Key Features

- **Hero & Brand Experience**: Immersive visual introduction with brand atmosphere and promotional highlights.
- **Service Catalog**: Detailed treatments menu including Moroccan Hammam, relaxation massages, aromatherapy, and aesthetic body rituals.
- **Visual Gallery**: High-resolution image showcase highlighting the spa's serene interior and private treatment suites.
- **Direct Appointment Inquiries**: Streamlined reservation form with date selection and service picking.
- **Interactive Location & Contact**: Embedded directions, operating hours, and instant messaging contact integration.
- **Responsive & Accessible**: Built with Radix UI primitives and Tailwind CSS for mobile-first fluid navigation.

## Technologies Used

- **React 19**
- **TypeScript**
- **Vite 7**
- **Tailwind CSS v4**
- **Radix UI** (Accessible headless UI components)
- **Framer Motion** (Smooth interactive animations)
- **Lucide React** (Icons)
- **Sonner** (Toast notifications)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [Bun](https://bun.sh/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedamarir-aseven/el-manar-spa.git
   cd el-manar-spa
   ```

2. Install dependencies:
   ```bash
   npm install
   ```
   *(or `bun install`)*

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
